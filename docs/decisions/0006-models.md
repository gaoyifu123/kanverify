# 0006 用哪几家的模型

- 日期：2026-11-21
- 状态：已定
- 谁定的：创始人

## 决定

评审团和其他 AI 任务用四家云端模型：

| 供应商 | 密钥在 `.env` 里的名字 |
| --- | --- |
| Anthropic | `ANTHROPIC_API_KEY` |
| Google Gemini | `GEMINI_API_KEY` |
| OpenAI | `OPENAI_API_KEY` |
| Mistral | `MISTRAL_API_KEY` |

- 四家正好组成四个成员的评审团，跨四家供应商。
- 每家具体用哪个型号，在做 AI 接口层时按各家当时的官方文档定，写进配置，不写死在业务代码里。
- 本地模型这次没有列入。接口层仍然保留这个位置，以后要加不用改业务代码（原则 8）。

## 密钥怎么放

- 密钥只放在项目根目录的 `.env` 文件里。这个文件不进版本库（`.gitignore` 已排除）。
- 格式照 `.env.example`。
- 密钥不写在看板上，不写在对话里，不写进任何文档。
- 密钥由创始人自己填。AI 不代填，也不读出来显示。

## 依据哪条原则

- 原则 8（不受制于人）：四家供应商，任何一家停用或涨价都不影响运转。
- 原则 7（能自动就不手动）：四个成员是评审团自动通过的前提。
