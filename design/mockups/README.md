# MVP 视觉稿（第四版，2026-11-22，已冻结，交给开发）

**设计到此冻结，开发按这一版实现。** 之后任何改动先回到设计。

这套是给开发用的 MVP 参考稿。规范文字在 `design/DESIGN.md`、`design/tokens.md`、`design/components.md`、
`design/ia.md`。`ia.md` 第 2 节写明了静态网站生成器要输出哪些文件。

直接用浏览器打开 HTML 文件即可，不联网。**人名、地名、出版方、引文和数字全部是虚构的**，网址都在
example.org 下，每页顶部有横幅标明。设计稿里不出现对真实人物的结论。

## 配色

创始人 2026-11-22 选定 B：每种结论一个亮度相近的柔和色（石灰、纸色、赭黄、蓝、淡紫、陶土），没有红绿，
颜色下面始终有花纹，旁边始终有文字标签。这是唯一的配色，没有切换。对比度计算见 `design/tokens.md`。

## 第四版改了什么（参考 memoiresdefrance.com，见 `design/reference-memoiresdefrance.md`）

- **六种结论**：加了“部分成真 / Partiellement réalisée / Partly came true”，图案是竖线“|”，
  和“成真”的“/”、“未成真”的“\”墨量相同。方法页写明：成真和部分成真可以提前判，未成真要等到期或本人放弃。
- **条目页的依据改成按日期排的一条线**：说出 → 凭据发布 → 截止 → 人工确认。内容和原来一样，只是按时间排。
- **列表行和首页卡片在结论下面显示两行说明**（待评估显示“还缺什么”）。
- **列表行可以就地展开**（原生 `<details>`，不靠脚本）：完整说明、依据文件和类型、截止日、确认日、完整记录的链接。
- **人物页按“在哪说的”分块**（来源文件 + 身份 + 日期），每块写出六个计数；领域改成筛选。
  页头加“结论截至某日”和覆盖范围一句；计数下面一句“这些是计数，不是评分”。
- **外观**：条目和卡片是白色圆角卡片；结论标签带小图标（就是图表里的那块花纹，不是打勾打叉）；
  页面标题和年份用衬线体（还是两个字号、两个字重）。
- **结论配色**：柔和色加花纹（创始人选定的 B），见上。

## 怎么检查

- 把浏览器宽度分别拉到 375 px、1024 px、1440 px 看。
- 人物页：点卡片展开再收起；点某个结论或话题筛选，再点一次取消；看每块的六个计数是否跟着话题和时间段变。
- 条目页：点依据线里的文件名或“programme”，对应的折叠行会自动展开。
- 切换深色模式。

## 依据哪条原则

原则 3（六种结论同等分量，不打勾打叉，不排名）、原则 1（“还缺什么”在行里也显示）、
原则 2（每个结论旁边都有说明和依据）、原则 5（只用已有字段，不改记录格式）、原则 8（不用网络字体和外部资源）。
