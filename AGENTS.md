# Instructions for any coding agent

This project keeps one set of instructions so that no AI vendor is required (principle 8).

1. Read `PRINCIPLES.md` first. The eight principles there override everything else.
2. Then read `CLAUDE.md`. It is written for Claude Code but applies to any agent:
   working rules, where things are, what not to do.
3. Team roles and hand-off formats are in `team/README.md`.

Talk to the founder in Chinese. Write code, identifiers and commit messages in English.
